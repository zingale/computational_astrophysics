*******************
Monte Carlo Methods
*******************

`Monte Carlo methods
<https://en.wikipedia.org/wiki/Monte_Carlo_method>`_ are a class of
methods that rely on random sampling to compute a numerical result.
The name stems from randomness of gambling at the `Monte Carlo casino
<https://en.wikipedia.org/wiki/Monte_Carlo_Casino>`_.

Monte Carlo methods are used for:

* numerical integration
* sampling distributions
* optimizing problems (i.e. finding the minimum of a high-dimensional function).

A key requirement for a Monte Carlo method is a good source of random numbers.
So we'll start by looking at random number generators.
